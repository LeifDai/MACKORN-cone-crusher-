# 液压圆锥破选型硬约束与判据（公开版）

## 一、七条硬约束（任一不满足 → 方案不成立）

| # | 约束 | 检查式 | 违反后果 |
|:---|:---|:---|:---|
| H1 | 给料上限 | `max_feed_mm ≤ 所选腔型的 maxFeedMm` | 堵腔、衬板异常磨损、主轴断裂风险 |
| H2 | 排矿口合规 | `cssMin ≤ css ≤ cssMax` | 产品粒度不可控、液压系统过载 |
| H3 | 产能达标 | `capacity_min_tph ≥ 单台需求` | 长期超负荷、电耗与衬板寿命恶化 |
| H4 | 段位与腔型匹配 | 中碎 → EC/C/MC；细碎 → M/MF/F；超细碎 → F/EF/EFX/EEF | 段位错配导致细度达不到或通过量骤降 |
| H5 | 系列选择 | 高细度/高通过量 → NS 高速型；大给料粗腔 → NH 标准型 | 选错系列导致余量假高、实际达不到 |
| H6 | 段数 | 总破碎比 F/P ≤ 6 一段；≤25 两段；≤100 三段 | 单段吃不下，被迫返工 |
| H7 | 台数经济性 | 单台余量比 `headroom_ratio ≤ 1.8` | 大马拉小车，投资与电耗双浪费 |

## 二、腔型选择规则（条件 → 结论）

- R1 给料最大粒度 < 50mm → 腔型池 `EF / EFX / EEF`
- R2 给料最大粒度 50-100mm → 腔型池 `F / MF`
- R3 给料最大粒度 100-200mm → 腔型池 `M / MC`
- R4 给料最大粒度 200-350mm → 腔型池 `C / EC`
- R5 给料最大粒度 > 350mm → 必须前段预筛分或改用粗碎设备（颚破/旋回）
- R6 需要最大通过量且产品可粗 → 同机型下选更粗的腔型（EC > C > MC > M > MF > F > EF）
- R7 需要更细产品 → 同机型下选更细的腔型，并同步下调 CSS
- R8 闭路细碎且要求 80% 通过 −10mm 以上 → 优先 EF 腔
- R9 中碎段给料含泥含水偏高 → 腔型放大一档并降低台时负荷，避免糊腔

## 三、产能判读规则

- R10 有腔型×CSS 详表数据 → 用详表区间（硬数据）
- R11 无详表机型 → 按系列区间外推，结论必须标注"近似"，并交技术复核
- R12 闭路系统 → 有效新给料能力 = 额定能力 ÷ 循环负荷系数（1.15-1.35）
- R13 余量比 1.0-1.35 → 最佳；1.35-1.8 → 可接受；> 1.8 → 降档或减台
- R14 台数 > 3 → 复核是否应换更大机型
- R15 矿石硬度高于中硬（f > 12）→ 台时能力按详表下限取值，并在报告中标注

## 六、数据使用纪律

- **禁止编造**：查不到的字段返回 `null` 并在 `warnings` 说明，绝不用默认值冒充。
- **每条数据带来源**：输出中的 `source` / `basis` 字段标明是厂商硬数据还是工程经验区间。
- **冲突并列保留**：同一指标多来源不一致时两个口径都留、标注统计边界，交人工裁决，不取平均。
- **参考价 ≠ 报价**：公开版不含价格数据；报价请走 MACKORN 商务。
- 正式投标前须由 MACKORN 技术人员复核并出具盖章版选型书。
